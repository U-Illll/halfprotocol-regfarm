## 一、签名算法（HMAC-SHA1）——✅ 100% 复现验证

### 1.1 密钥
| 项 | 值 | 来源 |
|---|---|---|
| KEY_SECRET | `222aiJodos2938JDdosko2djd82sf0` | feilin031 运行时 `rV=rz(rs.ACCESS_SEC, rs.ACCESS_KEY.SECRET)` |
| 签名用 key | KEY_SECRET + `&`（即 `222aiJodos2938JDdosko2djd82sf0&`） | 代码 `rB(r+"&", h)` — hook 双样本一致 |
| KEY_ID (AaduaneId) | `111jdk439dJJIjd023823201` | 请求参数 |

### 1.2 算法（feilin031 `rX` 函数，逐行等价）
```js
function rX(t, r) {                     // t=参数对象(不含Signature), r=KEY_SECRET
  delete t.Signature;
  var n = Object.keys(t); n.sort();     // ① 字典序排序
  var i = "";
  for (k of n) { i += (i ? "&" : "") + rZ(k) + "=" + rZ(t[k]); }   // ② kv 编码拼接
  var h = "POST&";                       // ③ 组装
  h = h + rZ("/") + "&" + rZ(i);
  return Base64.stringify(HmacSHA1(message=h, key=r+"&"));  // ④ HMAC-SHA1 → base64
}
function rZ(t){ return null==t ? null : encodeURIComponent(t).replace("+","%20").replace("*","%2A").replace("%7E","~"); }
```
**要点**：
- `i` 会被 **rZ 整体再编码一次** → 双重编码（如 Timestamp 的 `:` → `%3A` → `%253A`）
- rZ 的 `.replace()` 是 JS 字符串替换（**只替换第一个匹配**）——复刻时保持一致
- 最终 message 形如 `POST&%2F&AaduaneId%3D...%26Action%3D...`
- Signature 输出 = 28 字符 base64（或 40 hex）

### 1.3 复现验证（本地脚本 verify_sig.py）
```
样本1 InitCaptchaV3 : h(1630B) + key → 7a7e40f3bb00a9aa4b0ac99b10e1d38bfa8236ec  == hook 捕获 ✓
样本2 VerifyCaptchaV3: h(2521B) + key → 匹配 ✓
```

### 1.4 Python 复刻核心
```python
def rZ(t):
    if t is None: return None
    return urllib.parse.quote(str(t), safe="!~*'()-_.")

def sign(params: dict, key_secret: str) -> str:
    ks = sorted(params.keys())
    i = "&".join(f"{rZ(k)}={rZ(str(params[k]))}" for k in ks)
    h = "POST&" + rZ("/") + "&" + rZ(i)
    return base64.b64encode(hmac.new((key_secret + "&").encode(), h.encode(), hashlib.sha1).digest()).decode()
```

### 2.1 AES 基础配置（hook 双样本验证）
| 项 | 值 |

### 2.2 deviceToken 生成链（hook 实证）
```
① 服务器下发 deviceConfig(密文) → AES.decrypt(key1, iv)
   → 明文例: "3795d28242a11619bc25f786f84e53d4-h-1790659234396-f8682417b5d34a1bae8ac77875ed0663"（165B）
② 从①取前 16 字符作第二密钥（如 "e9d04fb0fa64dd17"）
③ AES.encrypt(设备指纹明文, key2, iv) → 密文 1312B
④ Base64(密文) → 876 字符
⑤ deviceToken = "SG_WEB#" + "设备ID段" + "#" + "base64分段..." 拼接
   实测总长：Init 1280 字符 / Verify 内 1336 字符
```

### 2.3 设备指纹明文格式（649B 样例）
